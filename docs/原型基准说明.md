# 套图工作台原型基准说明

## 结论

后续 PicAgent 套图工作台的开发，以本项目 `prototype/` 目录中的原型图为基准。

## 基准内容

- `prototype/picagent-suite-start.html`：套图创建首页；
- `prototype/picagent-suite-workbench.html`：套图创作工作台；
- `prototype/assets/`：上述页面依赖的样式、交互脚本、图标和示例图片。

## 开发约束

1. 页面信息架构、主要区域、核心操作顺序和现有交互文案默认保持与原型一致。
2. 正式代码可以替换原型中的静态数据和演示逻辑，但不能未经确认删除或改变核心流程。
3. 视觉细节可以随正式组件、真实数据和可用性验证进行收敛，但必须保持原型表达的工作台结构。
4. 如果需求需要改变页面结构、核心流程或交互行为，先更新 PRD 和本说明，再修改正式实现。
5. 本说明只适用于套图工作台；其他模式和后续页面必须使用各自独立的 PRD 与原型基准。

## 预览

在本目录运行：

```powershell
node prototype/server.js 4182
```

然后打开 `http://127.0.0.1:4182/`。
