# PicAgent 风格库（工作台资源库）V1 PRD

> 文档状态：核心 V1 已实现；爆品图反推兼容扩展待开发
> 版本：V1.3
> 更新时间：2026-08-31
> 终端：桌面端

## 1. 产品定位

“风格库”是 PicAgent 主应用内的独立资源页，不建设独立后台系统。V1 的实际领域对象为提示词模板和图片资产，名称保留“风格库”以兼容左侧导航入口和后续视觉资源扩展。工作台只消费风格库资源，不承载风格库管理弹层。

V1 主要服务三件事：维护可复用的提示词模板、保存和检索生产图片资产、让每个非实拍图片都能追溯到生成时提示词快照。资源库不替代提示词模板、不维护 RAG 商品资料，也不改变既有生成流程。

## 2. V1 范围

### 2.1 提示词模板

- 现有生成阶段保持为 `base_refine`、`plan`、`task_image`；爆品图反推新增独立 `reverse_prompt` 阶段；
- `reverse_prompt` 通过 `targetType=main|detail` 区分主图反推和详情图反推，不能替代或被其他阶段替代；
- 草稿编辑、复制新版本、发布、下线；
- 只允许已发布版本进入运行时选择；
- 发布版本不可原地修改，历史计划和任务继续引用原版本快照。

### 2.2 图片资产

- 商品实拍原图；
- 白底底图；
- AI 生成结果；
- 过程图；
- 终版图；
- 用户确认保存的爆品图反推资产（图片、反推提示词、视觉结构）。

除实拍原图外，图片必须展示对应生成提示词快照。过程图可以查看和追溯，但不能作为常规生成输入。

### 2.3 工作台入口

- 入口名称为“风格库”；
- 默认打开“图片资产”Tab，可切换“提示词模板”；
- 支持搜索、资源类型或模板阶段筛选；
- 中间列表、右侧详情、图片预览和提示词展示沿用工作台原型布局；
- 选择资源创建当前计划或任务引用，支持幂等、刷新恢复和移除引用。

## 3. 用户流程

```text
套图工作台
→ 打开风格库
→ 图片资产 / 提示词模板
→ 搜索或筛选
→ 查看详情、预览和提示词快照
→ 选择资源
→ 返回工作台继续生成
```

选择资源不立即生成图片，也不覆盖用户已经手动填写的核心提示词。计划目标只能选择 `plan` 模板，任务目标只能选择 `task_image` 模板；阶段不匹配时返回可恢复错误。

## 4. 状态与版本

图片资源状态为 `draft`、`published`、`archived`。草稿和归档资源不能新增引用，历史引用仍可读取。模板版本沿用现有模板版本模型，发布后不可原地修改；修改通过复制生成新草稿。

引用保存资源版本 ID、标题、类型、来源和提示词快照。引用归档只归档关系，不删除源资源。

## 5. 页面结构

- 顶部：标题、关闭按钮、资源库说明；
- Tab：图片资产、提示词模板；
- 工具栏：关键词搜索、资源类型或阶段筛选、搜索按钮；
- 列表：缩略图或无预览占位、名称、类型、状态、选择操作；
- 详情：资源类型、版本、来源、预览、完整提示词快照、选择或移除引用；
- 底部：当前工作台引用摘要和错误/成功反馈。

实拍原图在详情中明确显示“不适用生成提示词”；提示词缺失的非实拍资源显示数据异常提示，不使用当前模板正文冒充历史快照。

## 6. 数据与 API

资源库聚合既有 PostgreSQL 业务表和 MinIO 对象，不复制图片文件或 RAG 资料。核心接口包括：

- `GET /api/library/resources`：分页、搜索、类型、阶段、方案和状态筛选；
- `GET /api/library/resources/:id`：详情；
- `GET /api/library/resources/:id/preview`：归属校验后的预览代理；
- `POST /api/suites/:suiteId/library/references`：创建幂等引用；
- `GET /api/suites/:suiteId/library/references`：恢复当前引用；
- `DELETE /api/suites/:suiteId/library/references/:id`：归档引用；
- 模板生命周期接口：草稿编辑、复制、发布、下线；
- `POST /api/library/reverse-reference-assets`：保存爆品图反推资产；
- `POST /api/library/resources/:id/status`：更新图片资产状态。

## 7. 兼容性约束

- 不改变 `base_refine`、`plan`、`task_image` 语义和 `inputSchema` 动态表单；
- `reverse_prompt` 作为加法扩展接入现有模板版本、发布和查询机制，不改变既有阶段的运行目标；
- 不改变 PlanSnapshot、SuiteTask、TaskImageVersion、生成 provider 或 XYFlow 画布协议；
- 平台适配规则和商品资料继续由既有模块提供；
- PicAgent 只读使用 RAG，不维护 RAG 商品资料；
- 历史图片和计划通过快照保持稳定。

## 8. 明确不做

- 独立风格库后台、复杂权限和审批流；
- 风格实体、风格片段组合、相似度推荐或自动训练；
- RAG 商品资料上传、解析、事实审核和维护；
- 移动端、在线图片编辑器、风格市场和公开分享；
- 自动从图片反推完整商品事实；
- 修改现有生图 provider、任务状态机和画布布局协议。

## 9. 验收标准

- 工作台可打开“风格库”，默认图片资产 Tab；
- 图片和模板 Tab 可切换，搜索和筛选可用；
- 非实拍图片详情展示对应提示词快照，实拍原图显示不适用提示；
- 预览、阶段匹配、选择、刷新恢复和移除引用可用；
- 草稿、发布、下线、归档和历史引用规则符合约束；
- `npm run typecheck`、`npm run build`、全量契约测试和桌面浏览器验收通过。
