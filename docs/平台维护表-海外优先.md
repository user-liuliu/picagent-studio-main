# 目标平台维护表（海外优先）

## 用途

- `platform_profiles` 是目标平台的唯一维护来源。
- 生成简报中的“目标平台”只能从 `/api/platforms` 返回的启用记录中下拉选择。
- 前端提交平台 `code`；服务端再次校验平台是否存在并读取当前策略。
- LLM user 内容会附加所选平台的首图、主图组、文字和模特策略。
- 平台规则变动时，先更新 `db/migrations/009_platform_profiles.sql` 的维护数据，再重启 API 执行幂等更新。

## 字段

| 字段 | 说明 |
| --- | --- |
| `code` | 稳定的平台代码，提交给服务端和计划快照 |
| `name` | 下拉框展示名称 |
| `market_scope` | `overseas` 或 `domestic` |
| `main_image_strategy` | 首图生成约束 |
| `gallery_strategy` | 主图组/轮播图组织约束 |
| `text_strategy` | 图片文字和营销信息约束 |
| `model_strategy` | 模特使用约束 |
| `source_note` | 规则维护说明，具体站点和类目政策优先 |
| `sort_order` | 下拉排序；海外平台优先 |
| `enabled` | 是否出现在下拉选项中 |

## 运行约束

1. 平台为空或不在维护表中，计划提交失败，不回退为自由文本。
2. 目标站点/国家仍是独立输入，不与平台名称拼接成新的平台值。
3. 平台策略不能覆盖产品事实；商品外观、参数和功效仍以实拍图和已选资料为准。
4. 平台规则只作为生成约束，不代表对具体站点、类目、地区政策的法律或运营保证。
