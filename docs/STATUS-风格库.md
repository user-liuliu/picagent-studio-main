# 风格库状态

> 文档状态：已实现并完成 Ticket 05 集成验收  
> 更新时间：2026-08-24  
> 当前阶段：Ticket 01-05 全部完成  
> 说明：第一版是 PicAgent 主应用内的独立“风格库”资源页，实际维护提示词模板和图片资产；不再作为工作台弹层。

## 已确认决策

1. 第一版是 PicAgent 主应用内独立页面 `/style-library`，替换创建页左侧原“模板库”入口；不建设独立后台系统。
2. V1 实际领域对象只有提示词模板和图片资产；不扩展风格实体、风格片段组合或 RAG 维护。
3. 图片资产包括商品实拍原图、白底底图、AI 生成结果、过程图、终版图和爆品图反推资产。
4. 非实拍图片必须展示生成时提示词快照；实拍原图显示“不适用生成提示词”。
5. 过程图只能查看，不能作为常规生成输入。
6. 历史引用保存不可变资源版本和提示词快照。

## 已实现能力

- 主应用左侧导航“风格库”入口和独立资源页；
- 图片资产 / 提示词模板 Tab；
- 资源列表、搜索、类型或阶段筛选、右侧详情和预览；
- 非实拍资源提示词快照展示，实拍原图提示不适用；
- 计划或任务资源引用、幂等、移除和刷新恢复；
- 模板版本历史、草稿编辑、复制、发布、下线；
- 图片资源状态管理；
- 独立资源页保存爆品图反推资产（复用已有 MinIO objectKey），并保留反推提示词和视觉结构。

## 数据边界

- 业务真相来自 PostgreSQL 中的 `prompt_library.prompt_templates` 和 `prompt_library.prompt_template_versions`。
- 列表只展示已发布模板版本；模板详情可通过版本历史管理草稿，未发布版本不会作为可引用模板。
- 图片资产列表同时展示草稿、已发布和已归档状态，只有已发布资产允许创建工作台引用。
- 不使用 `suiteFixture`、原型静态数组或 `localStorage` 作为模板库数据源。
- 历史数据接口、repository 和迁移继续保留以兼容已有代码与测试；资源库不复制源图片、模板正文或 RAG 商品资料。

## 明确不做

- 风格实体、风格片段组合、独立后台和 RAG 商品资料维护；
- 把平台规则复制成风格内容；
- 独立后台系统、审批、推荐、分享或移动端；
- 修改生图 provider、任务状态机、PlanSnapshot、ImageVersion 或 XYflow 布局协议。
