# PRD-爆品图反推-V1

> 文档状态：已确认
> 版本：V1.1
> 日期：2026-09-01
> 项目：PicAgent 爆品图反推
> 终端：桌面网页端
> 原型：`prototype/picagent-product-reverse.html`

本文档定义 PicAgent“爆品图反推”独立功能。该功能直接替换现有“全能模式”入口和按钮，不保留“全能模式”占位。本文档不修改《PRD-套图工作台-V1》；后续生图复用套图工作台的共享 XYFlow 画布和统一生图能力。

## 1. 产品目标

设计师上传一张或多张爆品参考图，为每张图选择对应的主图或详情图反推模板，由 LLM 分别生成一条完整、可编辑、可保存的中文生图提示词。

反推结果用于复用参考图中的构图、空间、色彩、光影、材质和信息排版逻辑，但不得把参考商品的品牌、Logo、参数、功效或未经核验的卖点作为用户商品事实。

设计师可以把已生成的参考图和提示词带入与套图生成共用的 XYFlow 画布，后续从图片资源库选择产品白底图并继续生图。生成图片的产品保真和视觉效果由设计师人工校验，不建设机器通过判定。

## 2. 用户与使用场景

### 2.1 目标用户

首版以内部跨境电商设计师为唯一核心用户。模板维护、审核权限和多人协作沿用 PicAgent 后续统一能力，本 PRD 不新增角色。

### 2.2 典型场景

1. 设计师收集多张竞品或爆品主图，希望逐张提炼其版式和转化结构。
2. 设计师拆分一套详情页，希望逐屏提炼不同职责的详情图提示词，并保持系列色彩一致。
3. 设计师修改 LLM 反推结果后，将提示词带入共享画布，选择自己的产品白底图进行生成。
4. 某张参考图反推失败或结果不理想时，设计师只重新处理该图，不影响其他图片。

## 3. 核心概念

| 概念 | 定义 |
|---|---|
| 爆品反推方案 | 一次反推工作记录，包含一级模式、参考图顺序、模板选择、提示词结果和保存状态 |
| 爆品参考图 | 设计师上传、仅用于提炼视觉结构的图片，不作为用户商品外观真值 |
| 反推模式 | `主图反推` 或 `详情图反推`；同一方案只能选择一种模式 |
| 反推模板 | 提示词模板库中的已发布模板版本，规定分析规则、输入契约和输出格式 |
| 反推提示词 | LLM 针对一张参考图生成的一条独立、完整、可编辑的中文生图提示词 |
| 系列色彩基准 | 详情图模式下指定的一张参考图，仅提供整组色彩与光影秩序 |
| 爆品图反推资产 | 用户保存后可复用的参考图、提示词、模板版本和来源快照 |
| 产品白底图 | 后续生图时从图片资源库选择的产品外观真值图，不在反推上传区上传 |
| 产品素材组 | 一条反推提示词在一次生图任务中使用的有序白底图集合，最多 3 张；第一张为主产品图，其余为补充视角 |
| 生图任务输入版本 | 生图时冻结的提示词版本、产品素材组、爆品参考图、参考开关和生成参数的完整集合 |

## 4. V1 范围

### 4.1 必须实现

- 将创建页现有“全能模式”按钮和入口直接替换为“爆品图反推”；
- 不再展示“全能模式”或其“接口预留”状态；
- 新增桌面网页端爆品图反推页面；
- 支持 `主图反推` 和 `详情图反推` 两个一级模式；
- 单个方案只处理一种一级模式，不混合主图和详情图；
- 支持单图和多图上传，单个方案最多 16 张参考图；
- 支持 JPG、PNG、WebP；具体单文件大小沿用 PicAgent 统一上传限制；
- 支持删除参考图和拖拽调整顺序；
- 每张参考图必须单独选择一个反推模板；
- 不提供“将模板应用到全部图片”的快捷操作；
- 支持一次批量反推全部可执行图片；
- 支持单张重新反推；
- 每张参考图独立生成一条详细提示词，不自动合并多张图的非色彩元素；
- 详情图默认使用第一张图作为系列色彩基准，并允许设计师改选；
- 提示词可以查看、编辑、保存和复制；
- 反推结果不增加“草稿/已确认”双状态，生成后即可编辑、保存和进入画布；
- 保存方案后刷新页面可以恢复参考图顺序、模式、模板选择和提示词结果；
- 已保存结果可以归档为爆品图反推资产；
- 支持将已生成结果带入共享 XYFlow 画布；
- 进入画布时创建参考爆品图节点和反推提示词节点，并保持可点击映射；
- 在共享画布中通过资源库窗口为当前提示词追加 1–3 张产品白底图，支持选择、预览、排序、确认和取消；
- 允许同一白底图被多个提示词引用，并在画布中复用一个共享白底图资源节点；
- 默认将当前爆品参考图作为构图、版式、光影和视觉风格参考发送给生图 Provider，并允许关闭；
- 一次生图请求同时发送完整产品素材组、当前爆品参考图（若开启）和当前有效提示词，生成一个结果；
- 增加、删除、替换或排序白底图，或切换爆品图参考开关时创建新的生图任务输入版本；
- 支持新建爆品反推生图方案，或作为独立任务组追加到已有套图方案；
- 追加到已有方案时不得修改、重生或覆盖已有套图卡片；
- 冻结参考图、顺序、模板版本、模型请求摘要、LLM 原始输出和用户编辑后的提示词快照；
- 单张失败不影响其他图片完成，失败项可单独重试并显示错误原因。

### 4.2 复用现有能力

- 提示词模板库的模板版本和发布机制；
- 图片资源库的白底图选择能力；
- PostgreSQL 的业务关系、提示词快照和审计记录；
- MinIO 的参考图和缩略图对象存储；
- 现有 LLM Provider 适配、密钥管理和服务端调用边界；
- 套图生成共用的 XYFlow 画布、图片任务和图片版本能力；
- 共享画布中的后续白底图绑定、生图任务创建和生成结果展示。

### 4.3 V1 不实现

- 保留或重新建设“全能模式”；
- 移动端页面；
- 在反推页面内直接生成商品图；
- 在反推页面上传用户产品原图或白底图；
- 把爆品参考图作为用户产品外观真值；
- 让产品白底图参与反推 LLM 提示词生成；
- 在 Provider 不支持多图时静默丢弃白底图、只发送第一张或自动拼图；
- 多张参考图自动合并为一条综合提示词；
- 图片裁切、拼接、切片、抠图或像素级编辑；
- 自动识别并强制分配主图/详情图模板；
- 自动把一个模板应用到全部参考图；
- ControlNet、深度图、边缘图或姿态控制；
- 机器自动判定产品保真或视觉还原度；
- 复杂的审批、批量确认或多层结果状态；
- 新建一套独立生图画布或重复实现套图工作台的生图引擎；
- 自动复制参考图中的品牌、Logo、价格、参数、认证、功效或促销文案；
- 直接发布到电商平台。

## 5. 核心业务规则

### 5.1 入口替换

1. 创建页原“全能模式”按钮改名为“爆品图反推”。
2. 图标可以沿用现有 `sparkles`，状态由“接口预留”改为可进入功能的真实状态。
3. 点击后进入爆品图反推页面，不显示旧全能模式说明或入口。
4. 套图模式、单图模式、视频模式等其他入口不因本功能发生变化。

### 5.2 方案与模式

1. 新方案默认进入主图反推，设计师可以切换到详情图反推。
2. 同一方案中的全部参考图共享一级模式，但每张图单独选择具体模板。
3. 模式切换会使当前模板选择和已生成提示词失效，必须明确提示设计师后重新选择模板和反推。
4. 已保存方案再次打开时恢复上次模式和内容。

### 5.3 参考图上传与顺序

1. 一个方案至少上传一张、最多上传 16 张参考图。
2. 参考图按上传顺序保存并编号。
3. 支持拖拽调整顺序；顺序是提示词输出、画布节点创建和详情图系列浏览顺序。
4. 删除参考图只删除当前方案中的引用；已经归档的历史资产和审计记录不物理删除。
5. 已有提示词时调整顺序，不自动重新生成或覆盖提示词；设计师主动重新反推后才生成新结果。

### 5.4 模板选择

1. 模板来自提示词模板库的已发布版本。
2. 页面按一级模式过滤模板，不显示不适用的模板。
3. 每张参考图独立选择模板，未选择模板的图片不能进入反推队列。
4. 模板选择器展示模板名称、版本、简短适用说明和输入要求。
5. 前端不暴露完整 System Prompt 或隐藏模板正文。
6. 模板发生变更后，当前反推结果不自动覆盖；重新反推时冻结新的模板版本。

### 5.5 主图反推

首批主图模板包括：

| 模板 | 主要提炼内容 |
|---|---|
| 白底商品主图 | 商品占比、留白、阴影、清晰轮廓和基础信息区 |
| 场景主图 | 场景空间、主体关系、尺度、材质和商业光影 |
| 卖点信息主图 | 卖点层级、局部特写、标签、引线和信息模块 |
| 促销活动主图 | 活动标题、价格/权益区、角标和直接转化结构 |

每张主图独立提炼参考图自身的构图、色彩和信息结构，不借用其他图片的场景、道具或版式。

### 5.6 详情图反推

首批详情图模板包括：

| 模板 | 主要提炼内容 |
|---|---|
| 首屏 / 品牌表达 | 首屏气质、品牌表达、主体构图和标题留白 |
| 核心卖点 | 卖点表达、信息层级和产品聚焦关系 |
| 生活场景 | 使用关系、生活方式场景和空间层次 |
| 细节特写 | 材质、局部结构、微距视角和细节说明区 |
| 尺寸规格 | 尺寸标注、参数区、辅助线和比例关系 |
| 促销 / 信任背书 | 权益、认证、保障和信任信息的排版结构 |

详情图规则：

1. 默认第一张参考图为系列色彩基准，设计师可以改选任意一张。
2. 系列色彩基准只控制整组主色、辅助色、点缀色、明暗、色温和光影秩序。
3. 每张详情图的场景、构图、道具、材质关系和文案层级独立提炼，不在不同图片间混合。
4. 改选色彩基准不会覆盖已保存提示词；未生成图片和主动重新反推的图片使用新基准。

### 5.7 提示词生成规则

1. 一张参考图对应一次独立 LLM 请求和一条提示词结果。
2. 批量反推是多个独立请求的批次编排，不是把多张图片合并为一个模型输入后输出一条提示词。
3. 最终提示词正文必须可以在后续只提供用户产品白底图时独立执行；在共享画布实际生图时，系统默认额外发送当前爆品参考图作为可选构图/风格参考，但提示词不得依赖模型再次读取该图才能理解产品外观。
4. 提示词必须声明：用户产品白底图素材组是唯一产品外观参考，第一张为主产品图，其他白底图仅补充同一产品的角度、结构和细节；产品品类、轮廓、比例、结构、颜色、材质、包装和可见细节不得改变。
5. 参考商品的具体品类结构、品牌、Logo、参数、功效、认证和促销信息不得迁移到用户商品。
6. 不确定的商品文案使用明确占位符，不得由模型编造。
7. 提示词应把参考图版式转译为独立可执行的构图语言，不使用“参考图对应位置”“替换原产品”等依赖性表达。
8. 提示词主体使用中文；模型参数、输出格式和执行参数不混入视觉描述正文，由服务端执行契约管理。
9. LLM 只输出最终结果，不向前端展示后台分析过程或隐藏推理。

### 5.8 编辑、保存与复制

1. 右侧检查区展示当前选中参考图、模板和完整提示词。
2. 设计师可以直接编辑完整提示词并保存。
3. 保存后的用户版本是后续进入画布的有效提示词，不再自动被 LLM 原始结果覆盖。
4. 单张重新反推会生成新的结果并保留上一版快照，不能静默覆盖历史。
5. 复制操作复制当前编辑区的完整提示词。
6. 页面不增加复杂的结构化辅助面板，不要求设计师分别编辑摘要、保持项和禁止项。

### 5.9 失败与重试

1. 批量反推中每张图片分别显示等待、运行、成功或失败。
2. 单张失败不回滚或删除其他成功结果。
3. 失败项显示可理解的错误原因和“重新反推”操作。
4. 重试创建新的请求记录，保留原失败记录。
5. 页面刷新后从服务端恢复真实状态，不将运行中的请求误报为失败。
6. 生图任务失败重试必须复用失败 attempt 的完整输入版本；修改素材组、提示词、参数或爆品图参考开关后重新生成属于新的输入版本。

### 5.10 进入共享 XYFlow 画布

1. 已生成至少一条提示词后，可以进入共享画布。
2. 进入画布时只携带已有数据并创建：
   - 爆品参考图节点；
   - 对应的反推提示词节点；
   - 两者之间的一对一映射边。
3. 点击参考图节点可以定位对应提示词；点击提示词节点可以查看和编辑提示词。
4. 产品白底图在共享画布中从图片资源库选择，不在反推页面上传。
5. 白底图采用跨套图资源引用：不复制图片、不新增独立绑定实体，也不建设额外的白底图快照系统。
6. 白底图绑定后，画布再追加白底图节点、生图任务节点和生成结果节点。
7. 生图任务创建时必须记录实际使用的白底图资源 ID 和不可变资源版本信息；更换白底图时创建新的生图任务版本，不修改既有任务版本。
8. 画布关系为：`爆品参考图 + 反推提示词 + 产品白底图素材组 → 生图任务 → 生成结果`；同一白底图资源节点可被多个提示词和任务复用。
9. 进入已有套图方案时，反推内容作为独立任务组追加，不改变已有节点、任务、提示词或图片版本。
10. V1 进入画布时导入当前全部成功结果；等待中和失败结果保留在反推方案中，不创建画布节点。
11. 白底图选择窗口内未确认的勾选和排序不落库；未绑定白底图时任务卡显示“添加产品白底图”并禁用生成。
12. 每个任务节点只显示一个当前结果节点；历史结果保留在版本历史。输入版本变化后，在新结果生成前显示“输入已变更，尚未生成”。

### 5.11 人工校验

1. 系统不提供机器“通过/不通过”判定。
2. 设计师在共享画布中人工检查产品外观是否与白底图一致。
3. 设计师人工检查构图、色彩、光影、材质和信息层级是否达到反推目标。
4. 不新增自动相似度分数、机器阻断或自动审批状态。

## 6. 页面与交互

### 6.1 页面结构

桌面端采用三栏工作台：

- 左侧：功能名称、流程提示、主图/详情图模式、批量反推、保存方案和进入画布；
- 中间：上传区、参考图数量、参考图卡片、排序、删除、模板选择和单图状态；
- 右侧：当前选中图、当前模板、完整提示词编辑区、保存、重新反推和复制。

页面重点是重复处理多张图片的效率，不建设营销页、复杂说明页或嵌套卡片布局。

### 6.2 参考图卡片

每张卡片至少显示：

- 顺序编号；
- 图片缩略图；
- 文件名；
- 当前模板；
- 详情图模式下的系列色彩基准选择；
- 当前反推状态；
- 查看提示词或单张重试入口；
- 删除和拖拽排序操作。

卡片不直接铺开完整提示词，避免多图时页面过长。

### 6.3 提示词检查区

- 只展示当前选中图的信息；
- 提示词正文为主要可编辑内容；
- 模板可在当前图范围内调整；
- 保存、重新反推、复制三个动作保持清晰；
- 显示后续将从图片资源库选择产品白底图的提示；
- 不增加“草稿/已确认”切换或批量确认门槛。

### 6.4 原型基线

功能与布局基线以以下文件为准：

- `prototype/picagent-product-reverse.html`
- `prototype/assets/product-reverse.css`
- `prototype/assets/product-reverse.js`

当前原型是功能与信息架构基线，不是最终视觉定稿。正式开发沿用 PicAgent 现有桌面端组件、导航、图标和设计令牌。

## 7. 数据与快照

### 7.1 PostgreSQL

至少保存：

- 反推方案、一级模式、状态和更新时间；
- 参考图 ID、对象键、哈希、尺寸、mime、顺序和来源；
- 系列色彩基准图 ID；
- 每张图选择的模板 ID 和不可变模板版本 ID；
- 反推批次、单图请求、模型、请求摘要、状态、错误和重试关系；
- LLM 原始输出；
- 用户编辑后的当前提示词；
- 提示词版本和保存快照；
- 爆品图反推资产归档关系；
- 共享画布方案 ID、节点 ID 和映射关系；
- 关键操作审计记录。

历史提示词版本、失败请求和已被替换的模板版本引用不物理删除。

### 7.2 MinIO

MinIO 保存：

- 爆品参考图原文件；
- 用于列表展示的缩略图；
- 必要的预览图。

推荐对象键：

```text
reverse-plans/{planId}/references/{referenceId}/original
reverse-plans/{planId}/references/{referenceId}/thumbnail
```

数据库保存对象键和元数据，不保存临时签名 URL。

### 7.3 快照要求

每次成功反推至少冻结：

- 参考图 ID、哈希和顺序；
- 反推模式；
- 详情图系列色彩基准 ID；
- 模板及模板版本；
- 模型和 Provider 摘要；
- LLM 原始输出；
- 用户最终保存的提示词；
- 创建时间、重试关系和操作者。

进入共享画布时再冻结本次实际携带的参考图和提示词版本。每次点击白底图选择窗口的“确认使用”都会形成新的生图任务输入版本，冻结当前有效提示词版本、有序产品素材组中每张白底图的资源 ID 与不可变资源版本、爆品参考图版本、是否使用爆品图参考及生成参数。后续编辑提示词、增删替换或排序白底图不得改变已经存在的历史生成任务。

## 8. 模板与 Provider 契约

### 8.1 模板阶段

提示词库新增独立的 `reverse_prompt` 阶段。该阶段与 `base_refine`、`plan`、`task_image` 隔离，不能互相替换；普通生成阶段模板不得用于爆品图反推。

模板至少声明：

- `targetType`: `main` 或 `detail`；
- 模板名称、版本、适用说明和输入要求；
- 单图输入角色；
- 是否使用系列色彩基准；
- 输出 Schema；
- 禁止迁移的事实与品牌规则。

运行时只允许选择已发布的 `reverse_prompt` 模板版本，并要求 `targetType` 与当前方案模式一致：`main` 用于主图反推，`detail` 用于详情图反推。

### 8.2 反推 LLM 输入角色

发送给 LLM 的图片必须标记职责：

- 当前参考图：构图、风格、信息结构来源；
- 系列色彩基准图：仅在详情图模式中提供色彩与光影秩序；
- 不发送用户产品白底图；白底图只在后续共享画布的实际生图阶段绑定。

### 8.3 实际生图输入角色

共享画布创建生图任务时，Provider 输入必须显式区分：

- 产品素材组：最多 3 张有序产品白底图。第一张是主产品外观真值，其余是同一产品的补充视角、结构和细节；
- 爆品参考图：默认发送，可由设计师关闭，只提供构图、版式、光影和视觉风格；
- 当前有效反推提示词：描述可执行的视觉结构和文案占位符；
- 生成参数：由服务端作为执行元数据管理。

一次请求只生成一个结果。若 Provider 不支持当前输入所需的多图能力，服务端必须阻止生成并返回明确错误，不得静默丢图、只发送第一张或自动拼图。

### 8.4 输出契约

服务端应要求并校验结构化输出，至少包含：

```json
{
  "schemaVersion": "reverse-prompt-v1",
  "referenceImageId": "reference-id",
  "prompt": "完整中文生图提示词"
}
```

前端主要展示和编辑 `prompt`；其他追溯字段保存在服务端快照中，不增加复杂页面结构。

### 8.5 能力边界

- 模板描述的是反推任务，不等于生图 Provider 已收到产品图或参考图；
- 进入共享画布后，实际生图请求必须明确绑定完整产品素材组，并记录爆品参考图是否参与；
- 不支持的 mask、ControlNet、边缘、深度或姿态参数不得伪装成已启用能力；
- Provider 密钥、请求头、内部 URL 和隐藏模板正文只在服务端使用，不进入前端或日志。

## 9. 状态模型

### 9.1 反推方案状态

- `draft`：可以继续上传、排序、选模板和反推；
- `archived`：不再作为活动方案，但保留历史引用。

页面不向设计师增加复杂方案状态展示。

### 9.2 单图请求状态

- `pending`：等待反推；
- `running`：模型处理中；
- `succeeded`：已有可编辑提示词；
- `failed`：请求失败，可以重试。

保存提示词是内容操作，不增加“待确认/已确认”状态。

## 10. 验收标准

### 10.1 入口与范围

- 创建页不再出现“全能模式”；
- 原位置显示“爆品图反推”，点击可进入真实页面；
- 不影响套图模式和其他模式入口。

### 10.2 上传与模板

- 可以上传 1–16 张支持格式的参考图；
- 第 17 张被阻止并显示明确提示；
- 可以删除和拖拽排序；
- 每张图可以独立选择符合当前模式的模板；
- 未选择模板的图片不能开始反推；
- 页面不存在“应用到全部图片”操作。

### 10.3 主图与详情图

- 主图模式显示四类首批主图模板；
- 详情图模式显示六类首批详情图模板；
- 同一方案不能混用主图与详情图；
- 详情图默认第一张为系列色彩基准并可改选；
- 改选基准不会静默覆盖已保存提示词。

### 10.4 提示词生成

- N 张参考图产生 N 条独立提示词；
- 批量请求中一张失败不影响其他图片成功；
- 失败项可以单独重试；
- 每条提示词可以查看、编辑、保存和复制；
- 重新反推保留上一版快照；
- 刷新页面可恢复方案和真实请求状态；
- 提示词不复制参考图中的品牌、参数、功效等商品事实。

### 10.5 共享画布

- 至少一条提示词成功后可以进入共享画布；
- 当前全部成功结果各创建一组参考图节点和提示词节点；
- 点击图片与提示词可以互相定位；
- 产品白底图从图片资源库选择；
- 白底图使用跨套图资源引用，不复制图片或创建独立绑定实体；
- 当前提示词可绑定 1–3 张白底图，支持资源窗口内多选、排序、确认和取消；
- 同一白底图资源版本可被多条提示词分别引用，画布只显示一个共享资源节点；
- 生图请求同时携带产品素材组、可选的爆品参考图和当前有效提示词，单次生成一个结果；
- 生图任务记录实际使用的白底图资源版本，更换白底图会创建新的生图任务版本；
- 输入版本变化后旧结果保留在历史，新结果成功前显示“输入已变更，尚未生成”；
- Provider 不支持多图输入时阻止生成，不得静默降级；
- 追加到已有套图方案不会修改已有卡片或触发已有图片重生。

### 10.6 人工校验与安全

- 页面不展示机器保真评分或自动通过结论；
- 设计师可以在共享画布查看生成结果并人工判断；
- 前端、数据库快照和普通日志不泄露 API Key、Authorization、内部请求头或临时签名 URL；
- 完整隐藏模板正文只在服务端读取。

### 10.7 浏览器验收

- 在 1440×1000 桌面视口中三栏结构完整可用；
- 上传区、图片列表、模板选择和提示词编辑区无重叠或横向溢出；
- 16 张图片时列表可以滚动，左右栏保持可操作；
- 键盘可以聚焦模式、上传、模板、提示词和主要按钮；
- 批量反推、单张重试、保存、复制和进入画布均有明确反馈；
- 浏览器控制台无未处理错误。
